# TechSelect Content Creation & Product Publishing Master Guide

This guide defines the writing style, Amazon Associates compliance rules, component standards, and step-by-step workflow for publishing new products, reviews, and buying guides on **TechSelect India** (`https://techselect.blog`).

---

## 🚨 MANDATORY AMAZON COMPLIANCE RULES

Every single product page, review article, and buying guide MUST strictly comply with these 5 rules:

1. **NO STATIC PRICES (`₹...`)**
   - NEVER hardcode static prices (e.g. `₹2,75,990` or `₹49,900`). Static prices violate Amazon's Operating Agreement unless updated dynamically via PA-API with timestamps.
   - ALWAYS display `Check Latest Price` in price boxes and category cards.

2. **MANDATORY ABOVE-THE-FOLD DISCLOSURE BANNER**
   - Every product page (`app/products/*/page.tsx`) and article page (`app/article/*/page.tsx`) MUST feature the reader disclosure box directly below `<Breadcrumb />` before any affiliate links:
     ```tsx
     {/* Top Disclosure Banner */}
     <div className="mt-6 p-4 bg-muted/50 rounded-xl border border-border text-xs text-muted-foreground leading-relaxed text-center">
       <strong>Disclosure:</strong> TechSelect is reader-supported. As an Amazon Associate, I earn from qualifying purchases. When you buy through links on our site, we may earn an affiliate commission at no extra cost to you.
     </div>
     ```

3. **INLINE CTA DISCLOSURE TAGS (`(Earns Commission)`)**
   - Every outbound Amazon affiliate link/button MUST explicitly contain `(Earns Commission)` in the button text:
     - `Check Price on Amazon.in (Earns Commission)`
     - `Buy on Amazon.in (Earns Commission)`
     - `Amazon (Earns Commission)`

4. **DOMAINS & METADATA BASE**
   - Site domain: `https://techselect.blog`
   - Legal & Support Email: `support@techselect.blog`
   - Organization Name: `TechSelect India`

5. **REL & TARGET ATTRIBUTES**
   - All Amazon affiliate outbound links MUST feature:
     ```html
     target="_blank" rel="noopener noreferrer sponsored"
     ```

## ✍️ WRITING STYLE & TONE GUIDELINES

### 1. Conversational & Direct Tone
- Write like an expert colleague giving honest advice over coffee.
- Avoid corporate fluff ("We are thrilled to announce", "Best-in-class solutions", "Without further ado").
- Start directly with specific performance metrics and honest trade-offs.

### 2. Evidence-Based Testing Data
- Include concrete figures (e.g., *"Battery lasted 14 hours 22 minutes at 60% ANC volume"*, *"ANC attenuated low-frequency train rumble by ~28dB"*).
- Mention real-world testing environments (e.g., WFH, cafe background noise, Delhi metro commutes).

### 3. Clear Winners & Fair Trade-Offs
- State who should buy the product AND who should skip it.
- Never write pure praise; list genuine cons (e.g. glossy plastic fingerprints, heavy power brick).

## 🛠️ STEP-BY-STEP WORKFLOW: ADDING A NEW PRODUCT

Follow these exact steps whenever adding a new product or review to the codebase:

### Step 1: Generate & Save Product Image
1. Use `generate_image` tool with prompt:
   - *"High quality studio product photography of [Product Name], sleek minimalist background, professional consumer tech review lighting."*
2. Save the generated PNG image to:
   - `public/products/[product-slug].png`

### Step 2: Create Product Review Page (`app/products/[product-slug]/page.tsx`)
Create a new Server Component file at `app/products/[product-slug]/page.tsx`:

```tsx
import type { Metadata } from 'next'
import Image from 'next/image'
import { Header } from '@/components/header'
import { Footer } from '@/components/footer'
import { Breadcrumb } from '@/components/breadcrumb'
import { JsonLd } from '@/components/json-ld'
import { Star, Check, ExternalLink, Shield } from 'lucide-react'

const AFFILIATE_URL = "https://www.amazon.in/dp/YOUR_ASIN?tag=techstor0caaf-21"

export const metadata: Metadata = {
  title: '[Product Name] Review | TechSelect India',
  description: 'In-depth hands-on review of [Product Name] with real-world testing benchmarks and buying recommendations.',
}

const productSchema = {
  '@context': 'https://schema.org',
  '@type': 'Product',
  name: '[Product Name]',
  image: 'https://techselect.blog/products/[product-slug].png',
  description: 'Detailed analysis of [Product Name].',
  brand: { '@type': 'Brand', name: '[Brand Name]' },
  offers: {
    '@type': 'Offer',
    url: AFFILIATE_URL,
    priceCurrency: 'INR',
    availability: 'https://schema.org/InStock',
    seller: { '@type': 'Organization', name: 'Amazon.in' },
  },
}

export default function ProductPage() {
  return (
    <>
      <JsonLd data={productSchema} />
      <Header />
      <main className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-8 flex-1">
        <Breadcrumb
          items={[
            { label: 'Categories', href: '/' },
            { label: '[Category]', href: '/category/[category-slug]' },
            { label: '[Product Name]' },
          ]}
        />

        {/* Top Disclosure Banner */}
        <div className="mt-6 p-4 bg-muted/50 rounded-xl border border-border text-xs text-muted-foreground leading-relaxed text-center">
          <strong>Disclosure:</strong> TechSelect is reader-supported. As an Amazon Associate, I earn from qualifying purchases. When you buy through links on our site, we may earn an affiliate commission at no extra cost to you.
        </div>

        {/* Hero Section */}
        <div className="mt-8 grid lg:grid-cols-2 gap-10 items-start mb-12">
          <div className="bg-card border border-border rounded-2xl overflow-hidden aspect-square relative shadow-sm">
            <Image src="/products/[product-slug].png" alt="[Product Name]" fill className="object-contain p-8" />
          </div>

          <div>
            <span className="inline-block px-3 py-1 bg-accent/10 text-accent font-semibold text-xs rounded-full mb-3">
              Editor&apos;s Choice
            </span>
            <h1 className="font-serif text-3xl sm:text-4xl font-bold text-foreground mb-4">
              [Product Name]
            </h1>

            {/* Score & Price Box */}
            <div className="bg-muted/50 rounded-xl p-4 border border-border mb-6">
              <p className="text-xs text-muted-foreground mb-1">Price & Availability on Amazon India</p>
              <p className="text-xl font-bold text-foreground">Check Latest Price</p>
            </div>

            {/* CTA Button */}
            <a
              href={AFFILIATE_URL}
              target="_blank"
              rel="noopener noreferrer sponsored"
              className="amazon-btn flex items-center justify-center gap-2 w-full py-4 px-6 font-semibold rounded-xl transition-colors text-base shadow-sm"
            >
              Check Price on Amazon.in (Earns Commission)
              <ExternalLink className="h-4 w-4" />
            </a>
          </div>
        </div>
      </main>
      <Footer />
    </>
  )
}
```

### Step 3: Register Product in Global Metadata (`lib/categories.ts`)
Add the product entry into `SAMPLE_PRODUCTS` array in `lib/categories.ts`:
```ts
{
  title: '[Product Name]',
  description: 'Brief summary of testing results and score.',
  image: '/products/[product-slug].png',
  category: '[Category Name]',
  subcategory: '[Subcategory Slug]',
  rating: 9.2,
  price: 'Check Latest Price',
  amazonUrl: 'https://www.amazon.in/dp/YOUR_ASIN?tag=techstor0caaf-21',
  badge: "Editor's Choice",
  href: '/products/[product-slug]',
}
```

### Step 4: Register Route in Sitemap (`app/sitemap.ts`)
Add the product path to `sitemap.ts`:
```ts
'/products/[product-slug]',
```

